`app-store.svg` is Apple's official black "Download on the App Store" badge (US English), unmodified, from
https://toolbox.marketingtools.apple.com. Don't edit it; download a new copy from there if Apple updates it.

`google-play.png` is Google's official "Get it on Google Play" badge (US English), unmodified, from
https://play.google.com/intl/en_us/badges/static/images/badges/en_badge_web_generic.png. The PNG has clear padding
built in, so `StoreBadge` draws it larger with a negative margin to keep its visible height equal to Apple's badge, as
Google's badge guidelines ask. Don't edit it; download a new copy if Google updates it.
